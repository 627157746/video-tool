# PRD: 更新后自动重启 + 已有任务可重配保存形态

## Goal

1. **应用内更新完成后自动重启**应用，无需用户手动关闭再打开。
2. **已存在的下载/直播任务**可在详情中重新选择「保存视频 | 保存音频」，并在需要时失效已有媒体产物以便重下。

## Problem

| 现状 | 痛点 |
| --- | --- |
| 静默安装启动后提示「请关闭本应用并重新打开」 | 用户容易忘记；文件占用时安装可能不完整 |
| `media_save_mode` 仅创建时可设，详情只读 | 建错形态只能删任务重建 |

## Scope

### In scope

1. Windows 应用内静默安装：下载完成后调度「退出 → 安装 → 自动启动新版本」
2. 前端更新文案同步为「将自动重启」
3. 新 IPC：`update_job_media_save_mode`
4. 详情页下载/直播任务：可改保存形态（运行中禁用）
5. 形态变更且已有 ingest/媒体时：清空 `media/` 元数据与下游步骤，标记需重新下载/录制

### Out of scope

- 非 Windows 应用内安装
- 同时保存视频+音频
- 自动重跑 pipeline（仅失效，由用户手动运行）

## Acceptance

- [x] 安装更新成功后应用退出，安装完成后自动重新启动
- [x] UI 文案不再要求「请手动关闭再打开」
- [x] 已有 download / live_record 任务详情可切换 视频/音频
- [x] 运行中不可改；import 任务不展示编辑
- [x] 切换形态后旧媒体不作为有效产物；需重新执行 ingest
- [x] `pnpm typecheck` 通过；相关 Rust 单测通过
