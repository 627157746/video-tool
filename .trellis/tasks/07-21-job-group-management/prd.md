# PRD: 独立分组管理

## Goal

在设置中维护任务分组目录（增删改排序），任务挂接稳定分组 ID；列表按目录筛选，重命名不丢任务归属。

## User Stories

1. 在设置中新建、重命名、删除、调整分组顺序。
2. 创建/编辑任务时从目录选择分组，或输入新名称自动入库。
3. 重命名后，已归属任务仍显示新名称。
4. 删除分组后，原归属任务变为未分组。
5. 列表筛选芯片按目录顺序展示（含「全部」「未分组」）。

## Scope

- `AppConfig.job_groups: [{ id, name }]`，旧配置缺字段 = 空列表。
- Job.group 存 **group id**；旧自由文本 name 兼容解析。
- 设置页「任务分组」分区；与 Provider/模板同样走草稿 + 保存。
- 保存配置时：删除的分组 ID 会清空工作区内非运行任务的 `group`；若有运行中任务仍引用被删 ID，则拒绝保存。
- `update_job_group` / 创建任务：按 id 或 name 解析；未知 name 自动创建目录项。

## Non-goals

- 分组颜色/图标。
- 多标签。
- 跨工作区共享目录以外的同步。

## Acceptance Criteria

1. 设置可增删改排序分组并持久化到 config.json。
2. 重命名后任务列表/详情显示新名称。
3. 删除分组后任务变未分组。
4. 旧无目录/仅自由文本的任务仍可筛选显示。
5. typecheck / build / cargo test / clippy 通过。
